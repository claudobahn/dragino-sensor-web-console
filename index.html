Dragino Sensor Console

Configure Dragino -LB/-LS LoRaWAN sensors over Bluetooth using AT commands. Use Chrome or Edge on a desktop computer. Source, documentation and payload decoder on GitHub.

Not connected

Wake the sensor's Bluetooth first with a short button press (1–3 s) or a reset, then click Connect within 60 s and pick the device named after its DevEUI. If you enter the PIN from the label before connecting, the tool logs in automatically. The PIN is kept in memory only, never saved.

PS-LB / PS-LS settings

          

            Read from device loads the current values. Edit what you need, check the commands it will send,
            then click Write changes. Back up settings saves everything, including keys, as a script
            you can paste into the terminal to restore it, for example after a firmware upgrade. Each setting also shows the matching LoRaWAN downlink, so you can make
            the same change over the air once the sensor is deployed.
          

          

            
            
            
            
            
          

          

          

        


        

          
Live reading & water depth

          

            Converts the probe's 4–20 mA signal into depth for the probe range set below (an I4 probe is 0–4 m).
            Read now sends AT+GETSENSORVALUE=0, which powers the probe, samples it and prints the
            battery voltage and probe current (about 2 s). You can also type a current from a meter.

3. Test console

4. Discovery report

        

          Shows what was found plus the console transcript. Copy it or download it to share. Secrets are always
          removed from the report and from saved transcripts: the AT PIN, the LoRaWAN AppKey, NwkSKey and AppSKey, and
          any other 16-byte key. The console above still shows the real values.
